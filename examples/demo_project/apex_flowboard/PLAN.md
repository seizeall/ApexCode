# Apex Flowboard 执行计划

## 1. 项目目标

构建一个可离线运行的动态前端项目管理看板，用于完整展示 ApexCode 从“计划、实现、验证到预览”的 Agent 工作流。页面不是静态宣传页，用户可以创建、编辑、筛选、推进和删除任务，并实时查看进度统计与操作记录。

## 2. 交付范围

- `index.html`：语义化页面结构、工具栏、统计区、任务看板、活动记录和任务编辑弹窗。
- `styles.css`：桌面端与移动端响应式布局、明确的状态颜色、可访问的焦点态和稳定尺寸。
- `app.js`：任务状态管理、筛选搜索、表单校验、统计计算、活动记录和本地持久化。
- `assets/workspace-visual.png`：离线可用的本地视觉素材。
- `PLAN.md`：本文件，记录实施顺序和验收标准。

## 3. 用户场景

1. 用户打开页面后立即看到项目概况、完成率、任务分布和三列执行看板。
2. 用户通过搜索、状态和优先级筛选快速定位任务。
3. 用户可新建任务，填写标题、说明、负责人、优先级、状态和截止日期。
4. 用户可编辑已有任务，或通过任务卡按钮将任务推进到下一阶段。
5. 用户可删除任务；危险操作需要二次确认。
6. 所有修改写入 `localStorage`，刷新页面后仍然保留。
7. 用户可恢复演示数据，并在活动记录中看到关键操作。

## 4. 信息架构

- 顶部栏：产品标识、当前日期、新建任务按钮。
- 项目概览：项目名称、简短说明、整体完成进度和本地运行状态。
- 指标区：任务总数、进行中、已完成、临近截止四项指标。
- 控制栏：关键字搜索、优先级筛选、状态筛选、恢复演示数据。
- 看板区：`待规划`、`执行中`、`已完成` 三列，每列显示实时计数。
- 动态区：最近活动时间线与工作流视觉素材。
- 弹窗：新增/编辑任务表单。
- 提示层：保存、推进、删除、重置等操作反馈。

## 5. 数据设计

任务对象字段：

```text
id, title, description, owner, priority, status, dueDate, createdAt, updatedAt
```

- `priority`：`high | medium | low`
- `status`：`planned | active | done`
- 本地存储键：`apex-flowboard-state-v1`
- 活动记录保留最近 12 条，避免无限增长。
- 首次访问载入预置任务；解析失败时自动回退到安全的演示数据。

## 6. 交互与状态规则

- 搜索同时匹配任务标题、说明和负责人，不区分大小写。
- 多个筛选条件同时生效；无结果时显示明确空状态。
- 新建和编辑共用一个弹窗，标题和截止日期为必填项。
- 每张未完成任务卡提供“推进”按钮；已完成任务可重新打开。
- 卡片菜单提供编辑与删除入口，删除前使用确认对话框。
- 完成率按 `已完成数 / 任务总数` 计算；总数为零时显示 0%。
- “临近截止”定义为未来 3 天内且尚未完成的任务。
- 弹窗支持 `Escape` 关闭，焦点状态清晰，按钮均有可读标签。

## 7. 视觉与响应式策略

- 使用安静、务实的工作台风格：浅灰背景、白色工作区、深色正文，并以绿色、蓝色、琥珀色区分状态。
- 卡片圆角不超过 8px，不使用渐变、装饰光球或嵌套卡片。
- 桌面端采用三列看板；窄屏改为单列纵向布局。
- 固定工具栏、指标与卡片的最小尺寸，避免筛选或动态内容引发布局跳动。
- 视觉素材用于工作流概览，不承载关键文本，加载失败不影响功能。

## 8. 分阶段执行

### 阶段 A：基础结构

- 创建页面语义结构、图标资源引用和无脚本提示。
- 建立 CSS 变量、栅格、响应式断点和可访问焦点样式。

### 阶段 B：状态与渲染

- 定义种子数据、读取/写入本地存储和容错逻辑。
- 实现任务列表、列计数、统计指标、进度条和空状态渲染。

### 阶段 C：完整交互

- 实现搜索与组合筛选。
- 实现新建、编辑、推进、重开、删除和恢复数据。
- 实现表单校验、活动记录、操作提示和键盘关闭弹窗。

### 阶段 D：验证与展示

- 检查 HTML、CSS、JavaScript 语法与资源路径。
- 在 ApexCode 内置预览器启动页面。
- 验证桌面和移动视口，覆盖筛选、新建、编辑、推进、刷新持久化和重置流程。
- 修复溢出、遮挡、空白画面、控制台错误和不一致状态。

## 9. 完成标准

- 页面可通过 `index.html` 被 ApexCode 预览器识别并启动。
- 所有核心操作无需后端或外部 API 即可运行。
- 新增、编辑、状态切换、删除、搜索、筛选、统计与持久化均可验证。
- 桌面端和移动端无横向溢出、文字遮挡或不可触达控件。
- 浏览器控制台无运行时错误，本地素材可正常显示。
- 最终演示文档给出 Plan 模式提示词、Full 模式提示词和点击预览步骤。
